# Contributing

Thanks for contributing to Backpatch Action.

## Before opening a pull request

- Create a focused branch from `main`.
- Keep changes small and document any behavior change in the README.
- Run the CI checks locally where practical.
- Do not include credentials, API keys, customer manifests, or other sensitive data.

## Pull requests

Pull requests must pass CI and receive maintainer approval before merging. Contributors should not commit directly to `main`.

## Reporting problems

Use issues for bugs and feature requests. For security concerns, follow [the security policy](SECURITY.md).
